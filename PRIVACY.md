# Privacy Policy

The Bazhuayu Dify Plugin forwards user requests to the configured Bazhuayu MCP server.

## Data processed

Depending on the tool call, the plugin may process:

- Search keywords
- Template names and template IDs
- Task names
- Task parameters
- Task IDs
- Export preferences
- Preview rows returned by Bazhuayu

## Credentials

The plugin supports:

- Bazhuayu API Key
- OAuth access token and refresh token managed by Dify

Credentials are used only to authenticate requests to the configured Bazhuayu MCP server.

## Data storage

This plugin does not intentionally persist user task data or exported records. Dify may store plugin configuration and credentials according to the Dify deployment's own settings.

## Third-party transfer

Tool calls are sent to the configured Bazhuayu MCP server, which may call Bazhuayu backend services to search templates, execute tasks, and export data.
